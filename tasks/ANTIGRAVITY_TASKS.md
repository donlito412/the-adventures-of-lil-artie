Antigravity manages structure, coordination, file organization, and task flow.

Rules:
- Keep all agents coordinated.
- Prevent duplicate work.
- Track completed work.
- Review files before assigning work.
- Maintain project structure.
- Do not allow agents to overwrite each other.

1. Create full folder structure.
2. Create README.md.
3. Create all docs files.
4. Create all task files.
5. Create all agent notes files.
6. Create decision log.
7. Track completed tasks.
8. Track bugs and fixes.
9. Review project consistency.
10. Make sure Codex and Claude tasks stay separated.
11. Maintain clean project organization.
12. Prepare deployment checklist.
